Движок AJAX-фильтрации каталога WooCommerce, работающий через HTML-атрибуты pf-* в разметке темы.

== Description ==

PF Filter не диктует внешний вид карточек товаров, сетки или фильтров — вся разметка остаётся полностью на стороне темы/верстальщика.
Плагин находит разметку по атрибутам `pf-*`, строит фасетный фильтр (чекбоксы, радио, теги, дропдауны, диапазон цены, дерево категорий),
запускает AJAX-запросы к REST API и обновляет список товаров, счётчики, пагинацию и активные фильтры без перезагрузки страницы.

Первая загрузка страницы рендерится стандартным WordPress/WooCommerce loop — плагин не вмешивается в первичный рендер.

Полное описание атрибутов, REST API и структуры конфигурации — см. техническую спецификацию проекта.

== Installation ==

1. Загрузите папку `pf-filter` в `/wp-content/plugins/`.
2. Активируйте плагин через меню «Плагины» в WordPress.
3. Убедитесь что WooCommerce активен.
4. Настройте группы фильтров и сортировку на странице Настройки → PF Filter.
5. Разметьте страницу каталога атрибутами `pf-form`, `pf-target`, `pf-list`, `pf-output`, `pf-templates` и т.д.

== Changelog ==

= 1.1.0 =
* Исправлен пропущенный e.preventDefault() на пагинации — клик по стрелкам/номеру страницы прыгал в начало страницы вместо AJAX-запроса.
* Исправлено: карточки товаров и дизайн-превью пропадали/не открывались — Webflow-обработчики дропдаунов (w-dropdown-toggle) терялись при cloneNode() верхнего уровня группы; теперь для первого использования шаблона узел перемещается, а не клонируется.
* Дропдауны (сортировка и т.д.): контейнер для вставки опций теперь определяется по родителю существующего элемента списка, а не по классу Webflow/темы — работает независимо от вложенности разметки.
* Добавлена поддержка кастомных (локальных, не-таксономических) атрибутов товаров — плагин сам находит их в _product_attributes и позволяет фильтровать/сравнивать по ним наравне с глобальными pa_*-атрибутами.
* Убрано ручное переопределение групп по категориям (вкладка «По категориям»). Список групп теперь один — глобальный; в конкретной категории показываются только те из включённых групп, у которых есть хотя бы одно значение среди товаров этой категории.
* pf-loading/pf-empty: диагностировано и задокументировано — это стилизуется темой (display: none по умолчанию, .is-visible — показывает), плагин только переключает класс.

= 1.0.1 =
* Исправлены дублирующиеся шаблоны разметки (лишние Webflow-превью не убирались при построении групп фильтра, сортировки, пагинации и активных фильтров).
* Исправлена битая ссылка «В корзину» и другие построенные от текущего URL ссылки темы при AJAX-рендере карточек.
* Диагностика: устранена ложная ошибка `rest_cookie_invalid_nonce` при самопроверке REST API (loopback-запрос не передавал cookie текущего пользователя).
* Диагностика: `pf-target` больше не считается обязательным атрибутом — при одной форме и одном списке на странице это норма.
* Диагностика: общая проверка `[pf-filter-row]`/`[pf-filter-value]` больше не применяется ошибочно к шаблонам `range` и `category-tree`, у которых свои зацепки.

= 1.0.0 =
* Первая версия: REST API `/config` и `/products`, JS-движок фильтрации, страница настроек в админке.
